Exif Studio is a local metadata workbench for photos and videos. Open a folder or SMB share, browse, search, edit EXIF, find duplicates and read statistics. There is no import step and nothing is uploaded.

Capabilities

From thumbnails to EXIF to duplicate groups.

Everything works against local files. Caches are disposable; photos and videos are never moved or uploaded.

Virtualized browsing

Multiple folder tabs, continuous zoom, folder-group chips and filename/time/resolution sorting. Only visible rows are rendered.

EXIF view and edit

Camera, lens, exposure, focal length, GPS and capture time. Writes are validated and backed up first; unparseable structures are refused.

Duplicate detection

Local dHash and quality scoring group similar frames and mark the best one. Paged, waterfall and time-axis navigation.

Read-only video

MP4/MOV metadata, frame rate, resolution and posters. Opening an external player always asks first.

Invisible watermark

Writes an LSB watermark to a PNG copy, never the original. A local visual index survives screenshots and recompression.

Local API

Optional read-only HTTP API on 127.0.0.1 with Bearer tokens. Only metadata from already-opened folders is exposed.

How it works

First turn folders into entries. Then turn entries into answers.

Scanning, decoding and duplicate analysis run outside the UI thread. The interface polls results and repaints only when needed.

01 / DISCOVER

Read directory entries only

Discovery does not touch file metadata. Counts are pushed every 180 ms, so an SMB share shows progress within a second.

02 / PARSE

Parse in parallel

Up to 24 workers read size, timestamps and EXIF. A pure-Rust parser handles video containers; results are backfilled in filename order.

03 / CACHE

Disposable caches

Metadata, visual fingerprints and thumbnails use three cache layers. Clearing them only triggers a re-read, never a file change.

Screens

Statistics, not a spreadsheet. Duplicates, not a black box.

Charts are computed from the current folder. Duplicate groups show similarity, file count and the automatic pick; nothing is deleted.

Baseline

39,496 files. 37.1 seconds.

On a Windows machine over SMB, a folder with 37,215 images and 2,281 videos completed its first scan in about 37 seconds. Discovery showed up within a second, and the UI thread stayed responsive through repeated window resizes. Exact numbers depend on the network and disk; the architecture does not.

Build

Everything builds with Rust.

Rust stable 1.85+ is required. Windows is the primary development and test platform; macOS and Linux share the same code. Linux needs the usual X11/Wayland desktop dependencies and a CJK font.

  • No database, WebView or frontend build chain
  • No test photos in the repository; generate samples locally
  • EXIF writes create a .bak backup by default
# Clone and run
git clone https://github.com/for404cat/exif-studio.git
cd exif-studio
cargo run --release -- "D:\Photos"

# Generate local samples (not committed)
cargo run --example make_samples

# Checks
cargo fmt --check
cargo clippy --all-targets -- -D warnings
cargo test --all-targets
