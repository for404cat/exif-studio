# Contributing

[简体中文](CONTRIBUTING.md) | English

## Reporting issues

Please include:

- OS, app version or commit;
- folder size (file count, image/video ratio), local disk or SMB/UNC share;
- reproduction steps and actual result;
- relevant error text or logs.

Do not upload real photos, share addresses, usernames, API tokens or full-screen screenshots containing personal information. To show the UI, use media generated by `samples/` or redact sensitive areas.

## Code changes

1. Branch from `main`.
2. Keep the change focused; do not refactor unrelated modules while fixing a bug.
3. Explain new dependencies and the alternatives considered.
4. Run at least:

```bash
cargo fmt --check
cargo clippy --all-targets -- -D warnings
cargo test --all-targets
```

5. UI changes must be checked in a release build across Browse, Stats, Duplicates and Settings. Compiling is not enough.
6. Changes to EXIF writes, cache formats, scan concurrency or API permissions need tests and an explicit data-safety note in the PR.

Follow the existing style: user-facing errors are Chinese for now, technical details may stay English; comments should explain non-obvious constraints and reasons.
